A one-line slogan for a Solana wallet agent — built for the make.fun bounty "One-Line Slogan for a Solana Wallet Agent".

The slogan: **"Say it once, in plain English: your Solana wallet agent handles the rest."**

The line turns the wallet agent's real promise into a single contrast: you speak once, in plain words, and the agent does everything after that. No jargon, no stock crypto imagery — just the one-tap-intent idea, easy to say and easy to remember.

## Run it

```sh
node main.ts
```

This writes the slogan (one line, 13 words) to `/output/entry.txt`.
